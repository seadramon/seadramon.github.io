# Damar Margiwiguno Portfolio

Static portfolio site for GitHub Pages.

## Publish

1. Create the repository `seadramon.github.io` under the `seadramon` GitHub account.
2. Push this folder's contents to its `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`.

The site will be available at `https://seadramon.github.io` after GitHub finishes the first deployment.
